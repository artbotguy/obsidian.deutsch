
| Kategorie                        | 🎯 Wohin? (Richtung)                    | 🧭 Wo? (Ort / Zustand)                     | 🤔 Woher? (Herkunft)                      |
| :------------------------------- | :-------------------------------------- | :----------------------------------------- | :---------------------------------------- |
| **🏢 Orte** (Kino, Café)         | **in** das → **ins** Kino / Café        | **in** dem → **im** Kino / Café            | **aus** dem Kino / Café                   |
|                                  |                                         |                                            |                                           |
| **⚽ Aktivitäten** (Sport, Essen) | **zu** dem → **zum** Sport / Essen      | **bei** dem → **beim** Sport / Essen       | **von** dem → **vom** Sport / Essen       |
| **👤 Personen** (Arzt, Jana)     | **zu** dem → **zum** Arzt / **zu** Jana | **bei** dem → **beim** Arzt / **bei** Jana | **von** dem → **vom** Arzt / **von** Jana |
