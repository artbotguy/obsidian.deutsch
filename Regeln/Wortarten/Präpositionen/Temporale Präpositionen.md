## Konkrete Zeitangaben

==**um**== - в какое время
==**am (an dem)**== - *в какую часть дня, в какой день недели, в какой день месяца*
==**im (in dem)**== - *в каком месяце, в какое время года, в каком году*

| um     | am (an dem)                                                                            | im (in dem)                                                                                                                       |
| ------ | -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 10 Uhr | am Morgen, am Mittag, am Abend<br>`aber`<br>*in der Nacht*                             | im Januar, im Februar, im März, im April, im Mai, im Juni, im Juli, im August, im September, im Oktober, im November, im Dezember |
|        | am Montag, am Dienstag, am Mittwoch, am Donnerstag, am Freitag, am Samstag, am Sonntag | im Winter, im Frühling, im Sommer, im Herbst                                                                                      |
|        | am ersten Juli 2009                                                                    | im Jahre 2009                                                                                                                     |

## Unspezifische Zeitangaben



|            |                                                  |                                              |                                   |
| ---------- | ------------------------------------------------ | -------------------------------------------- | --------------------------------- |
| **seit**   | c / на протяжении                                | seit zwei Wochen                             | *на протяжении двух недель*       |
|            |                                                  | seit dem letzten Jahr                        | *с прошлого года*                 |
| **für**    | на                                               | für eine Stunde                              | *на час*                          |
|            |                                                  | für drei Tage                                | *на три дня*                      |
| **vor**    | до / ... назад                                   | vor dem Mittagessen                          | *до обеда*                        |
|            |                                                  | vor zwei Jahren                              | *два года назад*                  |

|            |                                                  | bis zum Ende des Monats                      | *до конца месяца*                 |
| **nach**   | спустя (после события) / через (в повествовании) | nach dem Meeting                             | *после совещания*                 |
| **==\|==** |                                                  | nach drei Tagen                              | *через три дня*                   |
