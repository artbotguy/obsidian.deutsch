

### Wechselprápositionen (предлоги с двумя падежами)
| Предлог      | Dativ = "Где?" (Wo?) | Akkusativ = "Куда?" (Wohin?) |
| ------------ | -------------------- | ---------------------------- |
| **in**       | in dem (im) Haus     | in das (ins) Haus            |
| **an**       | an dem (am) Tisch    | an den Tisch                 |
| **auf**      | auf dem Tisch        | auf den Tisch                |
| **über**     | über dem Tisch       | über den Tisch               |
| **unter**    | unter dem Tisch      | unter den Tisch              |
| **vor**      | vor dem Haus         | vor das Haus                 |
| **hinter**   | hinter dem Haus      | hinter das Haus              |
| **neben**    | neben dem Haus       | neben das Haus               |
| **zwischen** | zwischen den Häusern | zwischen die Häuser          |

### Akkusativ
[Мнемоника для Akkusativ-предлогов](https://www.youtube.com/watch?v=Ppu83SpNX08)

| Предлог         | Перевод | Пример                       |                                                        |
| --------------- | ------- | ---------------------------- | ------------------------------------------------------ |
| **entlang** (*) | вдоль   | diese Straße entlang         |                                                        |
| **durch**       | через   | durch den Park               |                                                        |
| **um**          | вокруг  | um das Haus                  |                                                        |
| **gegen**       | против  | gegen den Baum               |                                                        |
| **für**         | для     | für den Mann                 |                                                        |
| **ohne**        | без     | ohne die Frau                |                                                        |
| **bis**         | до      | <br>bis Berlin<br>bis Montag | **Только для:**<br>Городов/мест<br>Времени (дни, даты) |
### Только Dativ 
[Мнемоника для Dativ-предлогов](https://www.youtube.com/watch?v=XnRy9j6vm9c)

| Предлог   | Перевод   | Пример              |
| --------- | --------- | ------------------- |
| **aus**   | из        | aus der Stadt       |
| **bei**   | у, при    | bei der Arbeit      |
| **mit**   | с         | mit dem Freund      |
| **nach**  | после     | nach dem Konzert    |
| **seit**  | с (время) | seit dem Jahr       |
| **von**   | от        | von dem (vom) Vater |
| **zu**    | к         | zu der (zur) Mutter |
| **ab**    | от, с     | ab dem Montag       |
| **außer** | кроме     | außer mir           |
### Только Genetiv

| Предлог       | Перевод                       | Пример                                              |
| ------------- | ----------------------------- | --------------------------------------------------- |
| statt/anstatt | вместо                        | Wir gehen spazieren, **statt zu Hause zu bleiben**. |
| trotz         | несмотря на                   | Er war trotz allem gekommen.                        |
| während       | в то время как, в течение<br> | Während des Festes haben wir uns gestritten.        |
| wegen         | из-за                         | Er fehlt wegen Krankheit.                           |
| entlang (*)   | вдоль                         | Die Straße verläuft entlang der Küste.              |
