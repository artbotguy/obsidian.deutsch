## ==Bestimmte== und Unbestimmte Mengenwörter

| Группа       | Примеры                                  | Грамматическое название                                            |
| ------------ | ---------------------------------------- | ------------------------------------------------------------------ |
| **Группа 1** | _viele, einige, wenige, mehrere, manche_ | **Unbestimmte Mengenwörter** (неопределенные количественные слова) |
| **Группа 2** | ==_alle, beide, sämtliche_==             | **Bestimmte Mengenwörter** (определенные количественные слова)     |

| Слово       | Число             | Почему?                                                                                                                                              |
| ----------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **mancher** | Singular + Plural | Некоторый (один) / Некоторые (множество). Употребляется в обоих числах.<br>Часто взаимозаменяем с **einige**, акцент на части / выделении из группы. |
| **`jeder`** | Singular          | Каждый — это один представитель группы.                                                                                                              |
| **alles**   | Singular          | Всё — это одна целостная масса.                                                                                                                      |
| **`alle`**  | Plural            | Все — это множество отдельных людей/предметов.<br>====                                                                                               |
| **beide**   | Plural            | Оба — это двое, множественное число.                                                                                                                 |
| **viele**   | Plural            | Многие — это много, множественное число.                                                                                                             |
| **wenige**  | Plural            | Немногие — это мало, но множественное число.                                                                                                         |
| **einige**  | Plural            | Несколько — это множественное число.<br>Часто взаимозаменяем с **manche**, акцент на количестве.                                                     |

##### Местоимения ==jeder== и ==mancher== склоняются как определенный артикль. Во множественном числе местоимение jeder заменяется местоимением `alle`.

|     | N       | A       | D       | G       |
| --- | ------- | ------- | ------- | ------- |
| m   | jeder   | jeden   | jedem   | jedes   |
| n   | jedes   | jedes   | jedem   | jedes   |
| f   | jede    | jede    | jeder   | jeder   |
| Pl. | `alle`  | `alle`  | `allen` | `aller` |
|     | N       | A       | D       | G       |
| m   | mancher | manchen | manchem | manches |
| n   | manches | manches | manchem | manches |
| f   | manche  | manche  | mancher | mancher |
| Pl. | manche  | manche  | manchen | mancher |

---
##### Местоимение ==alles== склоняется тольуо в единственном числе.

**N. - alles, 
A. - alles, 
D. - allem [^1], 
G. (von) - alles [^2]**

[^1]: Dativ von alles:
**Формально не существует. Вместо этого используется von allem или aus allem, mit allem и т.д.**
*Ich träume von allem. (Я мечтаю обо всём.)*
*Er versteht von allem ein bisschen. (Он понимает понемногу от всего.)*

[^2]: Genitiv von alles:
**Практически не употребляется. Вместо него используются конструкции с von или замена на all- + существительное.**

---
##### Местоимения ==alle, beide==, einige, viele, wenige употребляются *только во множественном числе* и склоняются как определенный артикль (сильное склонение).

| N        | A        | D         | G         |
| -------- | -------- | --------- | --------- |
| ==alle== | ==alle== | ==allen== | ==aller== |
| ==beide==    | ==beide==    | ==beiden==    | ==beider==    |
| einige   | einige   | einigen   | einiger   |
| viele    | viele    | vielen    | vieler    |
| wenige   | wenige   | wenigen   | weniger   |


> [!NOTE] Title
> Существует разница между склонением прилагательных типа ==alle, beide== (*Bestimmte Mengenwörter*) и `einige, viele, wenige` (*Bestimmte Mengenwörter*)
> См. также: [[Deklination von Adjektiven]]

##### Если перед таким местоимением есть артикль (_die beiden_):
Тогда это уже **слабое склонение** для прилагательного (окончание *-en* во всех падежах, кроме Nom/Akk может быть *-en*).

| Падеж     | Beispiel                          |
| --------- | --------------------------------- |
| Nominativ | **die beiden** jung**en** Männer  |
| Akkusativ | **die beiden** jung**en** Männer  |
| Dativ     | **den beiden** jung**en** Männern |
| Genitiv   | **der beiden** jung**en** Männer  |
