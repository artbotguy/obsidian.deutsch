	# Суффиксация прилагательных в немецком языке

## 📌 Общее правило
**Суффиксы** присоединяются к **корню слова** (существительного, глагола, прилагательного) и меняют его значение, образуя новое прилагательное.

---
## 📊 Таблица суффиксов по значению

### 1. Суффиксы со значением «обладающий качеством» (от существительных/прилагательных)
| Суффикс     | Значение / Оттенок                                                                                          | Пример                                                                                  | Перевод                                       |
| :---------- | :---------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------- | :-------------------------------------------- |
| **`-ig`**   | Самый частый. «Имеющий что-то». Часто вызывает умлаут (ä, ö, ü).                                            | `der Staub` → **staubig**<br>`die Macht` → **mächtig**                                  | пыльный<br>могучий                            |
| **`-lich`** | «Характерный для, имеющий свойство». Часто отвлечённые понятия.                                             | `der Freund` → **freundlich**<br>`die Kunst` → **künstlich**                            | дружелюбный<br>искусственный                  |
| **`-isch`** | **1. Национальность.**<br>**2. Принадлежность к группе** (часто с негативным оттенком).                     | `Russland` → **russisch**<br>`das Kind` → **kindisch**<br>`der Egoist` → **egoistisch** | русский<br>детский (по-детски)<br>эгоистичный |
| **`-haft`** | «Наделённый свойством, склонный к». Часто от людей/явлений.                                                 | `der Fehler` → **fehlerhaft**<br>`der Trick` → **trickhaft**                            | ошибочный<br>хитрый, трюковой                 |
| **`-sam`**  | «Склонный к, обладающий свойством» (часто от прилагательных).                                               | `lang` → **langsam**<br>`wach` (бдительный) → **wachsam**                               | медленный<br>бдительный                       |
| **`-bar`**  | **«Возможность действия»** (часто от глаголов!). См. [[#2. Суффиксы от глаголов]].                          | `der Dank` → **dankbar**<br>`die Frucht` → **fruchtbar**                                | благодарный<br>плодородный                    |
| **`-er`**   | **Не склоняется!**<br>Ударение на первом слоге<br>**Города, некоторые регионы**<br>(происхождение из места) | `Köln` → **Kölner** Dom<br>`Schweiz` → **Schweizer** Alpen                              | Кёльнский собор<br>Швейцарские Альпы<br>      |

### 2. Суффиксы от глаголов
| Суффикс | Что образует | Пример | Перевод |
| :--- | :--- | :--- | :--- |
| **`-bar`** | **Пассивная возможность** («можно сделать»). **Золотой суффикс!** | `essen` → **essbar**<br>`lesen` → **lesbar**<br>`reparieren` → **reparierbar** | съедобный<br>читаемый<br>ремонтопригодный |
| **`-end`** | **Активное причастие I** (действие в процессе). | `laufen` → **laufend**<br>`blühen` → **blühend** | бегущий, текущий<br>цветущий |
| **`-ant` / `-ent`** | «Активно действующий» (от латинских корней). | `tolerieren` → **tolerant**<br>`existieren` → **existent** | терпимый<br>существующий |

### 3. Суффиксы со значением «лишённый, без» (отрицательные)
| Суффикс     | Значение                                    | Пример                                                             | Перевод                            |
| :---------- | :------------------------------------------ | :----------------------------------------------------------------- | :--------------------------------- |
| **`-los`**  | **«Без, не имеющий».** Очень продуктивный.  | `die Arbeit` → **arbeitslos**<br>`die Hoffnung` → **hoffnungslos** | безработный<br>безнадёжный         |
| **`-frei`** | **«Свободный от, не содержащий».**          | `der Alkohol` → **alkoholfrei**<br>`die Kosten` → **kostenfrei**   | безалкогольный<br>бесплатный       |
| **`-leer`** | **«Пустой, лишённый»** (часто абстрактное). | `der Inhalt` → **inhaltsleer**<br>`die Idee` → **ideenleer**       | бессодержательный<br>лишённый идей |

### 4. Суффиксы со значением «полный, богатый»
| Суффикс | Оттенок значения | Пример | Перевод |
| :--- | :--- | :--- | :--- |
| **`-voll`** | **Эмоциональная насыщенность** («полный чем-то»). | `die Hoffnung` → **hoffnungsvoll**<br>`die Sorge` → **sorgenvoll** | полный надежд<br>полный забот |
| **`-reich`** | **Объективное изобилие** («богатый чем-то»). | `der Erfolg` → **erfolgreich**<br>`die Erfahrung` → **erfahrungsreich** | успешный<br>богатый опытом |

## 🎯 Практическое правило выбора суффикса
| Если вы хотите выразить... | Используйте суффикс... | Пример |
| :--- | :--- | :--- |
| **«имеющий что-то»** (от сущ.) | **`-ig`** (основной), **`-lich`**, **`-isch`** | `sonnig`, `möglich`, `komisch` |
| **«можно сделать»** (от глагола) | **`-bar`** | `machbar`, `heilbar` |
| **«без чего-то»** | **`-los`**, **`-frei`** | `sinnlos`, `zuckerfrei` |
| **«полный чего-то»** (эмоции) | **`-voll`** | `liebevoll`, `achtsvoll` |
| **«богатый чем-то»** (объективно) | **`-reich`** | `wissensreich`, `einflussreich` |
| **«склонный к, похожий на»** (иногда негатив) | **`-haft`**, **`-isch`** | `lebhaft`, `launisch` |

---
## ⚠️ Важные нюансы
1.  **Умлаут (Umlaut):** При добавлении `-ig`, `-lich` корень часто меняет гласную.
    - `die Kraft` → **kräftig**
    - `die Macht` → **mächtig**
2.  **Конкуренция суффиксов:** Один корень + разные суффиксы = разные значения.
    - `künstig` (ловкий) vs `künstlich` (искусственный)
3.  **Суффикс `-bar` — это пассив:** `lesbar` = «можно прочитать» (кем-то), а не «может читать».
