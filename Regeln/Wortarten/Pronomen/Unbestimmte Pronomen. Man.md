### man
Неопределённое местоимение man (кто-то, люди, ты в общем смысле) существует только в Nominativ. 
Для всех остальных падежей используются формы от [[Unbestimmte Pronomen. Man#einer|einer]].

### einer

| Падеж     | Mужской род | Женский род | Средний род | Множественное число |
| --------- | ----------- | ----------- | ----------- | ------------------- |
| Nominativ | **einer**   | eine        | eines       | welche / einige     |
| Akkusativ | **einen**   | eine        | eines       | welche / einige     |
| Dativ     | **einem**   | einer       | einem       | welchen / einigen   |
|           |             |             |             |                     |
