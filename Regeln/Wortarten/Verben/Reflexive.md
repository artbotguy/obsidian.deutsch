
| sich setzen              |                   |
| ------------------------ | ----------------- |
| *ich setze mich*         | *wir setzen uns*  |
| *du setzt dich*          | *ihr setzt euch*  |
| *er, sie, es setzt sich* | *Sie setzen sich* |


В вопросах с возвратными глаголами местоимене (_uns, dich, sich_) **всегда** ставится **после подлежащего**, но **перед смысловым глаголом** в инфинитиве.
