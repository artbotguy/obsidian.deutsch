

## Виды

| Критерий         | Тип глагола                              | Характеристики                                   | Примеры                                                            |
| ---------------- | ---------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------ |
| **По структуре** | **1. Простые (einfache Verben)**         | Состоят из одного корня                          | gehen (идти), sagen (говорить), kommen (приходить)                 |
|                  | **2. Сложные (zusammengesetzte Verben)** | Образуются с приставками                         |                                                                    |
|                  | - a) Неотделяемые приставки              | Ударение на корне, приставка не отделяется       | be- (besuchen), er- (erzählen), ver- (vergessen), ent- (entdecken) |
|                  | - b) Отделяемые приставки                | Ударение на приставке, отделяется в Present/Past | an- (anrufen → Ich rufe an.), auf- (aufstehen → Ich stehe auf.)    |
|                  | - c) Двойные приставки                   | Могут быть отделяемыми/неотделяемыми             | über- (übersetzen/übersetzen), unter- (unterhalten/untergehen)     |
|                  | **3. С дополнением**                     | Требуют фиксированного падежа                    | warten auf (+Akk.), sich freuen über (+Akk.)                       |
|                  |                                          |                                                  |                                                                    |
| **По функции**   | **1. Переходные**                        | Требуют Akk.-дополнения                          | lesen (Ich lese ein Buch.)                                         |
|                  | **2. Непереходные**                      | Не требуют дополнения                            | schlafen (Ich schlafe.)                                            |
|                  | **3. Возвратные**                        | Используют sich                                  | sich freuen (Ich freue mich.)                                      |
|                  | **4. Модальные**                         | Выражают возможность/необходимость               | können, müssen, wollen                                             |
|                  | **5. Вспомогательные**                   | Для образования времён                           | haben, sein, werden                                                |
|                  | **6. Движения/состояния**                | Описывают движение или состояние                 | gehen, liegen, stehen                                              |
|                  |                                          |                                                  |                                                                    |
| **По спряжению** | **1. Слабые**                            | Не меняют гласную, стандартные окончания         | machen – machte – gemacht                                          |
|                  | **2. Сильные**                           | Меняют гласную в Past/Partizip II                | schreiben – schrieb – geschrieben                                  |
|                  | **3. Смешанные**                         | Меняют гласную, но имеют окончания как слабые    | denken – dachte – gedacht                                          |
