
## Man + *Verb*

| Конструкция              | Значение               | Пример                            |
| ------------------------ | ---------------------- | --------------------------------- |
| **man kann** + Infinitiv | можно                  | **Man kann** hier schwimmen.      |
| **man muss** + Infinitiv | нужно                  | **Man muss** pünktlich sein.      |
| **man darf** + Infinitiv | разрешено              | **Man darf** hier nicht rauchen.  |
| **man soll** + Infinitiv | следует (рекомендация) | **Man soll** viel Wasser trinken. |
| **man sagt, dass...**    | говорят, что...        | **Man sagt**, dass er reich ist.  |
## Man + Verb VS Passiv

|man + Akkusativ|Passiv (Nominativ)|
|---|---|
|Man baut **das Haus**.|**Das Haus** wird gebaut.|
|Man trinkt **viel Kaffee**.|**Viel Kaffee** wird getrunken.|
|Man isst **Brezeln**.|**Brezeln** werden gegessen.|
