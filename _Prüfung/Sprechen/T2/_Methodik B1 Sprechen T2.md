
> [!NOTE] Title
> Стоит учиться писать не предложения а конструкции (набросок)

## Слайд 1 - презентовать тему + показать структуру
```
Hallo! Mein Thema ist "...". In meiner Präsentation spreche ich zuerst über meine persönlichen Erfahrungen, dann über die Situation in meinem Heimatland. Danach erzähle ich von den Vor- und Nachteilen des Themas und äußere meine Meinung. Am Ende können Sie noch Fragen stellen.
```

# Слайд 2 - личный опыт
```
Meine Erfahrungen. ...
```

# Слайд 3 - родина
```
Die Situation in meinem Heimatland. ...
```

# Слайд 4 - преймущества, недостатки, мнение
```
Vor- und Nachteile. ...
Meine Meinung: ...
```

## Слайд 5 - концовка
```
Das wäre alles.
Haben Sie noch fragen?
```

## Вопрос после презентации собеседника
```
Dankeschön für Ihre Präsentation, sie hat mir sehr gut gefallen! Ich möchte Sie bitte fragen: Was denken Ihre Eltern / Großeltern / Tante... (о ком не шла речь) zu dem Thema?
```
